# pair-mini-competition

Week 1
- Abbey: Quantum ESPRESSO + GROMACS
- Dilara: miniBUDE + WRF

Week 2:
- Abbey: miniBude + WRF
- Dilara: Quantum ESPRESSO + GROMACS


## miniBUDE
**Goal**: Complete as many iterations of the bm2 input as possible within one hour on one node.

**Source**: https://github.com/UoB-HPC/miniBUDE


## WRF
**Goal**: Complete as many timesteps of the CONUS 12km benchmark as possible within one hour using up to four nodes.

**Source**: https://github.com/wrf-model/WRF

**Docs**: https://www2.mmm.ucar.edu/wrf/users/docs/user_guide_v4/contents.html


## Quantum ESPRESSO
**Goal**: Run the GRIR443 benchmark as fast as possible using up to two nodes.

**Source**: https://github.com/QEF/q-e

**Docs**: https://quantum-espresso.org/Doc/pw_user_guide/user_guide.html


## GROMACS
**Goal**: Maximise performance in ns/day for the benchMEM benchmark using two nodes.

**Source**: https://github.com/gromacs/gromacs

**Docs**: https://manual.gromacs.org/current/index.html
